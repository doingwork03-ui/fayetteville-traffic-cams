# Fayetteville Traffic Cams

Interactive map of the NCDOT traffic cameras around Fayetteville, NC, with live snapshots and live video.

**Open it:** https://doingwork03-ui.github.io/fayetteville-traffic-cams/

Camera images and video come from [DriveNC.gov](https://drivenc.gov) (NCDOT). Don't use while driving.
